# Babette Klingenberg – Website-Relaunch

Modernisierte Website für [babette-klingenberg.de](https://www.babette-klingenberg.de/) im
"Warmes Atelier"-Design (Editorial-Stil, Terrakotta/Olive, Seitennavigation), erstellt auf Basis
der Original-Texte und -Bilder sowie zusätzlich recherchierter, aktueller Ausstellungsinfos.

## Ansehen

`index.html` lokal im Browser öffnen, oder über GitHub Pages (siehe unten) live ansehen.

## GitHub Pages aktivieren (einmalig)

1. Repo auf GitHub öffnen → **Settings → Pages**
2. Unter „Build and deployment": Source = **Deploy from a branch**
3. Branch = `main`, Ordner = `/ (root)` → **Save**
4. Nach ca. 1–2 Minuten ist die Seite unter `https://<username>.github.io/BabetteKlingenberg/` erreichbar

## Was übernommen wurde

- **Texte**: wörtlich von der Original-Website (Vita, Meine Arbeit, Malerei, Illustration, Karten, Ausstellungen bis 2011, Kontakt)
- **Bilder**: Original-Thumbnails aus `images/` (Logo, Portrait, Gemälde-, Illustrations- und Kartenkategorien) sowie 5 neuere, betitelte Arbeiten aus einem aktuellen Online-Portfolio (`images/portfolio-neu/`)

## Ausstellungen – zusätzliche Recherche (neu ggü. den ersten Entwürfen)

Die Original-Website endet mit Stand 2011. Für einen zeitgemäßen Auftritt wurde ergänzend
recherchiert, was seither öffentlich über Babette Klingenbergs künstlerische Aktivität zu finden
ist. Ergebnis – neu in Vita und Ausstellungsliste eingearbeitet:

| Info | Quelle |
|---|---|
| Seit 2008 Mitglied im Künstlerkreis Neuried | Profilseite Künstlerpalette Unterschleißheim |
| Seit 2013 Dozentin für Acrylmalerei, ASZ Solln-Forstenried & VHS Pullach/Baierbrunn | ebd.; Wochenanzeiger München |
| 2017: Vernissage des eigenen Acrylmalerei-Kurses, ASZ Solln-Forstenried | Wochenanzeiger München, 20.03.2017 |

| 5 neuere Werktitel („Mysterium“, „Frühling“, „Wolken“, „Das Haus“, „Freude“) mit Maßangaben | Portfolio-Profil auf dasauge.de |

**Nicht übernommen** (gefunden, aber nicht ausreichend verifizierbar oder nicht eindeutig zuordenbar):
- Eine Pressemitteilung der Stadt Unterschleißheim zu einer Jahresausstellung „Kontraste“
  (Bürgerhaus Unterschleißheim, Angabe „bis 17.01.2025“) ließ sich nicht direkt abrufen
  (Zugriff verweigert) – daher nur indirekt bestätigt, nicht einzeln in die Liste aufgenommen.
- Zwei weitere Ausstellungsformate der Künstlerpalette („KunstHerbst“, „Der Zauber der Natur“)
  sind als wiederkehrende Gruppenformate belegt, aber ohne konkretes Jahr/Datum für eine
  Teilnahme von Babette Klingenberg persönlich – daher nicht als eigener Listeneintrag geführt.
- Ein Eintrag „Elisabeth Babette Klingenberg“ als Dozentin an der VHS Eching wurde bewusst
  **nicht** übernommen – Eching passt nicht zum sonstigen München/Pullach-Kontext, vermutlich
  eine andere Person gleichen Namens.

**Wichtig:** Diese Angaben stammen aus öffentlich zugänglichen Quellen (Vereins-/Künstlergruppen-Websites,
Lokalpresse), nicht von Babette Klingenberg selbst. Vor Veröffentlichung der Seite sollten die
Ausstellungsdaten und insbesondere die neueren Werktitel/Maße mit ihr abgestimmt werden.

## Offene Punkte / Annahmen

- **Bildauflösung**: Die übernommenen Thumbnails sind klein (Original ~134×101 px, neuere Werke ~80×80 px). Für den finalen Launch sollten hochauflösende Originalbilder von Babette Klingenberg eingebunden werden.
- **Kontaktformular**: rein optisch, kein Versand-Backend. Für den Relaunch empfiehlt sich ein Form-Service (z. B. Formspree, Netlify Forms).
- **Preise** (Karten 2,50 €, Kalender 8,00 €) stammen unverändert von der Originalseite – vor Veröffentlichung auf Aktualität prüfen.
- **Impressum**: Aus Datenschutzgründen wurde die im Original genannte Technik-Umsetzerin (Drittperson) nicht übernommen; bei Bedarf im finalen Impressum ergänzen.
